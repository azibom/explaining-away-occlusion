# Explaining Away Occlusion

A browser-based classroom experiment and ten-slide presentation of:

> Kang, B., Midler, B., Chen, F. & Druckmann, S. (2026). **Recurrent connections facilitate occluded object recognition by explaining-away.** *Nature Communications, 17*, 2225. https://doi.org/10.1038/s41467-026-68806-5

## What this project does

The site begins with a short, two-condition psychophysics demonstration:

1. A fixation cross appears for 500 ms.
2. A single object appears for 500 ms.
3. After a 25 or 50 ms gap, a highly occluded scene appears for 400 ms.
4. The visitor chooses which of two objects was behind the foreground object.

In the **same-occluder** condition, the first object is identical to the scene’s foreground object. In the **random-object** condition, it is unrelated. The comparison makes the paper’s explaining-away hypothesis directly experienceable.

The experiment is followed by a ten-slide, keyboard-navigable presentation covering:

- the paper’s 23-model architecture comparison;
- the important computational-depth result;
- prediction-order and hidden-state perturbation tests;
- the human psychophysics result;
- Recon-Net and iterative reconstitution;
- representational findings, limitations, and relevance to consciousness research.

## Scientific scope

This is an **independent educational reimplementation**, not the authors’ official experiment or a scientific replication.

- The published human experiment allowed up to 400 trials and retained 41 of 182 starters after quality control.
- This classroom version uses 20 measured trials and original procedural stimuli.
- A visitor’s result is descriptive and should not be interpreted as evidence about that person.
- Browser and display timing varies by device.
- The project stores and transmits no responses.

The repeated foreground object in the same-occluder condition is intentional: it is the experimental manipulation, not accidental stimulus reuse. Target objects are unique across the short run.

## Original implementation and data

The authors’ research code and data are available separately:

- [Official research repository](https://github.com/KangByungwoo/occlusion_public_repo)
- [Zenodo archive](https://doi.org/10.5281/zenodo.17655370)
- [Open-access article](https://doi.org/10.1038/s41467-026-68806-5)

Their repository contains the network experiments, human response data, and analysis notebooks. This project does not copy or replace that code; it provides a browser-first explanatory experience with original stimuli and visualizations.

## Run locally

No build step or backend is required.

```bash
python -m http.server 4176
```

Then open `http://127.0.0.1:4176/`.

## Controls

- Experiment: left/right arrow keys or pointer
- Presentation: left/right arrows, Page Up/Page Down, or Space
- Jump: Home/End
- Fullscreen: presentation control in the lower-right corner
